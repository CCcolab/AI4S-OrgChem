## 1. 判定规则（统一）

对每条命题 `P`，独立计算后给出唯一判定：

| 判定 | 含义 |
|------|------|
| **一致** | 在约定的理论层次、基组与参考定义下，独立计算结果在符号、量级与关键数值上支持原著论断，且能经受专家对参考态/方法选择的追问 |
| **非一致** | 独立结果在符号、量级或关键结论上与原著相悖，或原著论断在其自身定义下不可复现 / 依赖不可辩护的约定 |

**硬性要求（可辩护性）**：
1. 每条命题必须写成**可证伪陈述**：明确自变量、观测量、阈值与对照。
2. 必须同时报告：**与原著同口径结果** + **对参考态/方法敏感性**（若敏感性翻转结论，则不得轻易判“一致”，除非原著明确主张该参考态选择本身）。
3. 不得把“与原著数值碰巧接近”当作充分条件；必须说明物理/化学含义是否成立。
4. 最终判定只允许 **一致 / 非一致**；若证据不足，状态保持“论证中”，不提前判。
5. **证据质控硬闸（强制）**：写 `VERDICT.md` 前必须通过拓扑/正确分子、几何健全、收敛（或双向滞后等代理）、能量尺度合理、作废数据隔离。**严禁**在「未收敛 + 错误分子」上定判。权威规格：[`quality_gates.md`](quality_gates.md)。

**符号约定**（与原著一致）：稳定化能为负，去稳定化能为正。能量报告单位：kcal/mol。

## 3. 命题详细规格

### P1 — 丁二烯共轭能符号依赖参考分子选择

**原著主张**：文献用丁二烯 vs 两分子 1-丁烯的氢化热差 (−3.9 kcal/mol) 证明共轭稳定；若改用 **trans-2-丁烯** 为参考，共轭能为 **+1.9 kcal/mol（去稳定）**。GL 方法给出 ΔE ≈ +1.4 kcal/mol，与之接近。若经典证据不被否定，全书框架无意义。

**传统对立**：共轭稳定化是有机结构基本原理；丁二烯单键短于乙烷、氢化热差为负，是经典证据。

**可证伪验证**：
1. 在同一理论层次（建议起步：B3LYP/6-31G*，再交叉 RHF/MP2 或更高）计算  
   - CE₁ = ΔH_hyd(丁二烯) − 2·ΔH_hyd(1-丁烯)  
   - CE₂ = ΔH_hyd(丁二烯) − 2·ΔH_hyd(trans-2-丁烯)  
2. **一致判据**：CE₁ < 0 且 CE₂ > 0（符号翻转可复现）；CE₂ 量级落在 +1–3 kcal/mol 区间。  
3. **非一致判据**：CE₂ 仍为负，或无法在合理热化学定义下复现符号翻转。

**工具**：WSL/PySCF 几何优化 + 反应能；ZPE；自研 2007-GL（`src/localization/`）。  
**Canvas**：`p1-butadiene-ce.canvas.tsx`  
**实施计划**：[`implementation/P1_计划表.md`](../implementation/P1_计划表.md) · [`implementation/P1_计算与论证表.md`](../implementation/P1_计算与论证表.md)
**判定**：L1/L2 **非一致**（无符号翻转）；L3 对书 +1.4 **非一致（量级）**（自研 ΔE≈+4.06）。

### P2 — π 离域（共轭）去稳定且驱动畸变（总命题）

**原著主张**：π–π、非键 σ–σ 相互作用去稳定并驱动畸变；π–σ 亦去稳定但阻碍扭转；大扭转角是三者折中。共轭稳定化作为“基本原理”应被质疑。

**传统对立**：共轭稳定化使共平面最稳定；构象是共轭与位阻的折中。

**可证伪验证**（汇总性命题，依赖 P3/P5/P6）：
1. 在 NBA 类或定域几何框架下，独立分解得到的关键相互作用能符号与原著一致（π–π、σ–σ 去稳定；畸变驱动力归宿正确）。  
2. **一致**：至少两类关键体系（NBA 型 + 多烯/芳香定域）均复现“π 离域去稳定 / 驱动畸变”。  
3. **非一致**：主流可辩护分解下相互作用符号系统性相反，或畸变驱动力归宿错误。

**工具**：LFMO/π–σ 分解的独立实现（仅按公开定义）；PES + 能量分解。  
**Canvas**：`p2-conjugation-destabilization.canvas.tsx`（总评）  
**实施计划**：[`implementation/P2_共轭去稳定总命题_计划实施表.md`](../implementation/P2_共轭去稳定总命题_计划实施表.md)

### P3 — NBA 类：大扭转角拥挤构象最稳定

**原著主张**：NBA 实验扭转角约 36°–55°；弛豫 PES 上 θ≈θ_exp 时分子能最低，且该点核排斥极大、电子能极小——**拥挤构象最稳定**。

**传统对立**：位阻去稳定 → 大扭转/拥挤构象能量升高。

**可证伪验证**：
1. 对 Ph–N=CH–Ph（及 1–2 个杂环类似物）做弛豫 PES（扭转角 θ）。  
2. **一致判据**：E(θ) 最小值落在大角区（约 30°–60°，与晶体量级一致）；在该区附近 EN 相对平面构象升高、Ee 降低的定性趋势可复现。  
3. **非一致判据**：全局最小在近平面（θ≲15°），或大角区仅为次级极小且显著更高。

**工具**：PySCF 弛豫扫描；Ee/EN 分解；**拓扑门禁 + 质控闸**（[`quality_gates.md`](quality_gates.md)）。  
**Canvas**：`p3-nba-twist.canvas.tsx`  
**实施计划**：[`implementation/P3_计划表.md`](../implementation/P3_计划表.md) · [`implementation/P3_计算与论证表.md`](../implementation/P3_计算与论证表.md)

### P4 — 苯 D₆ₕ：核排斥主导 vs π 电子畸变倾向

**原著主张**：从定域 GL → 离域基态，ΔEe > 0、ΔEN < 0 且 |ΔEN| > ΔEe；键长均等时核排斥最小，导致 D₆ₕ。

**传统对立**：π 离域驱动等键长与芳香稳定。

**可证伪验证**：
1. 沿 BLA（键长交替）坐标扫描苯：记录 E、Ee、EN。  
2. **一致判据**：总能量最低在等键长附近；沿趋向等键长的路径，核排斥变化对稳定化的贡献主导（或至少与原著定性一致：Ee 不利、EN 有利）。  
3. **非一致判据**：Ee 变化主导稳定化，或等键长处并非 EN 极小。

**工具**：BLA 扫描 + Ee/EN 分解（可先不做完整 GL）。  
**Canvas**：`p4-benzene-d6h.canvas.tsx`  
**实施计划**：[`implementation/P4_苯D6h核排斥_计划实施表.md`](../implementation/P4_苯D6h核排斥_计划实施表.md) · [`implementation/P4_计算与论证表.md`](../implementation/P4_计算与论证表.md)  
**判定**：本层级 **一致**（BLA + Ee/EN；完整 GL→G 另计）。

### P5 — 局部共轭 ΔEAm 恒去稳定并使单键伸长

**原著主张**：对大量双键对，ΔEAm = E(GE-m)−E(GL) > 0；中间单键在 GE-m 中比 GL 更长；r 与 ΔEAm 可拟合。

**传统对立**：局部共轭稳定（能量降低）并使连接单键缩短。

**可证伪验证**：
1. 独立实现 GL / GE-m（按公开矩阵删除定义），对丁二烯、己三烯、苯等计算 ΔEAm 与 Δr。  
2. **一致判据**：样本中 ΔEAm 符号以正为主；对应单键 Δr > 0（伸长）。  
3. **非一致判据**：在合理定域定义下 ΔEAm 系统性为负，或单键系统性缩短。

**工具**：自定义 Fock/重叠/交换积分约束的 SCF + 优化。

### P6 — 无参数 ESE 基准：苯与环丁二烯

**原著主张**：  
ESE = ΔEA − ΣΔEAm = E(G) − E(VR)。  
苯 ESE ≈ **−36.3** kcal/mol；环丁二烯去稳定共轭/反芳香能 ≈ **+53–55** kcal/mol；二者符号与实验一致是方法合理性的必要条件。

**传统对立**：芳香稳定化能通常依赖等键/均键反应或经验参数；数值因参考反应而异。

**可证伪验证**：
1. 按公开定义独立实现 2011/2014 口径的定域几何与 ESE。  
2. **一致判据**：苯 ESE < 0 且 |ESE| 落在约 30–40 kcal/mol；环丁二烯对应量 > 0 且量级约 45–60 kcal/mol；对理论层次/基组不过度敏感（原著强调此点）。  
3. **非一致判据**：符号错误，或量级偏离实验/原著过远且无法用合理实现差异解释。

**工具**：完整定域几何 + 可加性 + 虚拟参考分子。  
**Canvas**：`p6-ese-benchmarks.canvas.tsx`  
**实施计划**：[`implementation/P6_无参数ESE基准_计划实施表.md`](../implementation/P6_无参数ESE基准_计划实施表.md)

### P7 — 张力芳香：BLA 源于 π 离域而非角张力

**原著主张**：在 PLG（排除中心环与稠合小环间 π 相互作用）中，Δr 从基态大正值降至近零 → BLA 归因于 π 离域。

**传统对立**：Mills–Nixon 效应——角张力导致中心环键长交替。

**可证伪验证**：
1. 对苯并三环丁二烯（或文献常用张力芳香模型）比较 G vs PLG 的 Δr = r_endo − r_exo。  
2. **一致判据**：排除中心–外周 π 耦合后 |Δr| 显著下降（趋近 0）。  
3. **非一致判据**：排除 π 耦合后 Δr 基本不变 → 支持角张力主导。

**工具**：PLG 构造（公开定义）+ 几何比较。  
**Canvas**：`p7-strained-aromatic.canvas.tsx`  
**实施计划**：[`implementation/P7_张力芳香BLA_计划实施表.md`](../implementation/P7_张力芳香BLA_计划实施表.md)

### P8 — 呋喃类：LDE 而非 ESE；介于芳香与非芳香

**原著主张**：呋喃类 ΔEA > 0 且 ΔEA < ΣΔEAm，故 (ΔEA−ΣΔEAm)<0 但不宜称 ESE；应称 LDE；与苯类不可直接比。

**传统对立**：呋喃常被视为芳香杂环。

**可证伪验证**：
1. 计算呋喃/吡咯等的 ΔEA、ΣΔEAm、差值符号模式。  
2. **一致判据**：复现“ΔEA>0 且差值仍为负”的模式，并与苯（ΔEA<0）定性区分。  
3. **非一致判据**：呋喃与苯落在同一符号模式，无法支持“中间态/LDE”区分。

**Canvas**：`p8-furan-like.canvas.tsx`  
**实施计划**：[`implementation/P8_呋喃类LDE_计划实施表.md`](../implementation/P8_呋喃类LDE_计划实施表.md)

### P9 — 大环 [N]annulene 趋于多烯

**原著主张**：N 从 8 到 26，VDE 仍守 4n+2；但 N≳16 后 [4n] 与 [4n+2] 的 VDE/π 趋于接近，大环更像多烯。

**传统对立**：大环仍应显著表现芳香/反芳香。

**可证伪验证**：
1. 计算一系列 [N]annulene 的 VDE（或等效离域指标）随 N 变化。  
2. **一致判据**：小环遵守 4n+2 符号分离；大 N 时 |VDE/π| 差距收敛。  
3. **非一致判据**：大 N 仍保持强烈、不收敛的芳香/反芳香分离。
