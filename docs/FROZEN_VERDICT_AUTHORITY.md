### L0 五态定义

| 状态 | 含义 | 可否对外称「支持」 |
|------|------|-------------------|
| `SUPPORTED_WITHIN_SCOPE` | 同 estimand、预注册协议内达阈 | 可以，**必须带范围** |
| `PARTIAL` | 仅子命题/单体系/趋势通过，或关键异议未闭合 | 仅「部分支持」 |
| `OPPOSED` | 同 estimand 下预注册阈值未满足 | 对该 estimand 称不支持 |
| `INDETERMINATE` | 证据不足、收敛失败、关键方法缺失 | 不可强判 |
| `INCOMPARABLE` | 估计量/参考态/符号约定不同 | 不可投票、不可平均 |
| `DERIVED` | 仅汇总其他命题，无新增 QM 数据 | **不可**计入独立验证数 |

## 5. 什么 **不算** 改判

1. **L0 五态修订**（本文 §2）：响应第三方复审的**治理整改**，不声称新 QM 重算。  
2. **L1 快照保留**：2026-08-25 二元审计 **不删除**，仅降级为历史记录。  
3. **措辞 / metadata / 校验器升级**：工程加固。  
4. **P2 标 `DERIVED`**：身份澄清，不改变汇总逻辑。

**真正改判 L0** 须：新证据 + 预注册 + G1–G5 + 更新 `VERDICT.md` + 同步 L2/L3 + git 审计说明（同旧 §5 精神）。
