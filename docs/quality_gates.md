[English](quality_gates.en.md) | **中文**

> **目的**：杜绝再出现建立在「未收敛 + 错误分子」上的一致/非一致判定。  
> **触发**：P3（2026-08-23）——欠收敛假 PES 曾误写非一致；`_phenyl` 建环错误使计算对象不是 NBA。  
> **效力**：写 `deliverables/unit/Pn/VERDICT.md` 前的**强制清单**；Cursor Agent 见 `.cursor/rules/ai4s-quality-gates.mdc`（`alwaysApply: true`）。

## 2. 定判前五道闸（缺一不可）

| # | 闸门 | 通过标准（示例，命题可收紧） | 失败处置 |
|---|------|------------------------------|----------|
| G1 | **化学图 / 拓扑** | 键连、配位数、环尺寸与目标分子一致；脚本 `check_topology`（或等价）返回空缺陷列表 | 立即中止计算；修几何；旧结果标作废 |
| G2 | **几何健全** | 无原子重叠（建议 dmin ≥ 0.85 Å）；关键键长在合理窗 | 同上 |
| G3 | **收敛可辩护** | 各关键点优化收敛；**或**有独立代理（如双向 PES 滞后 ≤ 1 kcal/mol） | 加大 maxiter / 换协议；**不**用未收敛曲线定判 |
| G4 | **能量尺度** | 构象/对照 ΔE 落在化学合理窗（命题在计划表写明；构象典型 ≲ 数十 kcal，出现 10² 须拒收） | 拒收本轮 PES/表；查未松弛键长/错误分子 |
| G5 | **证据路径洁净** | 正式表在 `results/Pn/tables/`；作废数据仅在 `results/Pn/invalid_*/` | 迁移坏数据；VERDICT 禁止引用 invalid |

**只有 G1–G5 全过**，才允许在 `VERDICT.md` 写 **一致** 或 **非一致**。  
任一未过 → 状态保持 **论证中 / 待定**（待定 ≠ 验证失败）。

## 3. 反面教材（P3）

| 阶段 | 错误 | 后果 |
|------|------|------|
| 初版弛豫 | maxiter 过短；ΔE ~10² kcal | 读数 E_min≈75° → 曾误写**非一致** |
| 加严第一轮 | 建环 bug → 七元含氮环 | E_min≈90°、自由最优≈垂直 — **答非所问** |
| 修正后 | 六元环 + 拓扑门禁 + 双向滞后 + ΔE~2 kcal | E_min≈44.9°、自由 B3LYP≈34.5° → **一致** |

教训：**翻转来自纠正方法学错误，不是同一证据改口。**

## 4. 代码与落盘约定

### 4.1 每个几何相关命题包必须

1. 实现拓扑/键连断言（P3 参考：`src/p3_nba/geometry.py` → `check_topology`）。  
2. 在 **构建后、预松弛后、扫描每点后** 调用；失败 → `SystemExit`（或等价硬失败）。  
3. 结果 JSON 含 `quality_gate`（或同名结构），字段至少包括：  
   - `passed: bool`  
   - 拓扑 / dmin / θ 或坐标误差 / ΔE 跨度 / 收敛或滞后  
4. `passed == false` 时：`agree`（或自动判定旗标）必须为 `null`，**禁止**脚本打印「建议判一致/非一致」。

### 4.2 作废数据

```
results/Pn/invalid_<原因>/   # 例：invalid_wrong_geometry/
```

- 迁入后主路径 `tables/`、`summary*.md` 不得再把该数据当正式证据。  
- `VERDICT.md` / `report.md` 可**点名作废**并说明原因，但不得用其数值支撑终裁。

### 4.3 单元完成定义补充

在 `docs/directory_structure.md` 既有 DoD 之上，增加：

- [ ] G1–G5 在计算与论证表中勾选通过  
- [ ] `quality_gate.passed == true`（或书面等价证明）  
- [ ] 若曾有 invalid 归档，VERDICT 已声明不引用

## 5. 各命题最低几何自检（起步清单）

| 命题 | 最低自检要点 |
|------|----------------|
| P1 | 原子数/化学式；关键 C–C 键长窗；优化后无重叠 |
| P3 | 两苯环均为六元；ipso 配位=3；N–C / C=N 键存在；θ 定义原子非共线 |
| P4 | 苯六元环；BLA 变形不破坏拓扑 |
| P5–P9 | 定域/大环：环尺寸与价态；虚拟参考不得 silently 改成另一分子 |

新命题开工时把本表行写入该命题**计划表**「质控闸」一节。

## 6. Agent / 人类操作纪律

1. **完成度口号**（如「80%」）**不能**替代 G1–G5。  
2. 聊天中的「看起来支持/反对」**不是**判定；仅 `VERDICT.md` 作数。  
3. 发现拓扑或尺度异常 → **先停算、归档、修门禁**，再重跑；禁止「先出个判定再说」。  
4. 环境缺包（如 `geometric`）记入缺口并询问用户；不得用「装不上优化器」当借口跳过 G3。

## 9. GL / PLG 能量口径（形式说明）

自研 `src/localization/gl_2007.py`、`plg.py` 等通过修改 Fock / 重叠矩阵块求解修正 SCF，报告能量取自收敛 `kernel()` 返回值。

**在本项目中的表述**：

- 这些量为按原著公开矩阵删除规则定义的 **operational estimator（操作性估计量）**；
- **不**自动等同于同一标准哈密顿量下的变分约束能，除非完整拉格朗日量与一致梯度已另行证明；
- 写 VERDICT 时：数值达预注册阈值 → 可记 L1 **一致**；解释层须区分「复现书中估计量」与「物理因果唯一性」。

此节 **不改变** 2026-08-25 已冻结的 L1 判定。
