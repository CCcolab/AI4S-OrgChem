# P9 技术报告：大环 [N]annulene — N=8–18 gap 收敛趋势

## 1. 命题与对立

| | |
|--|--|
| 原著主张 | 大环 [N]annulene（N≳16–18）在离域能意义上趋于多烯，芳香/反芳香性实质减弱。 |
| 传统对立 | 4n+2 规则对大环仍具实质芳香/反芳香意义。 |
| 本项目判据 | 一致：小环 [4n]/[4n+2] 的 VDE 符号分明，且随 N 增大两类差距单调收敛；非一致：差距不收敛，或符号模式在大环被破坏。 |

## 2. 方法

```bash
PYTHONPATH=. python3 -m src.p9_annulene.run_v1 --basis '6-31g*'
PYTHONPATH=. python3 -m src.p9_annulene.run_v2b
```

- 几何：平面 Kekulé（交替单双键）
- 观测量：垂直 VDE **代理** = ESE = ΔEA − ΣΔEAm（2007 GL/GE-m 口径），按 π 电子数归一得 VDE/π
- 层次：B3LYP/6-31G*
- 敏感性：2011-lite（额外删除片段间交换块）；BLA 几何（1.34/1.46 Å）

## 3. 结果

### 3.1 主序列（B3LYP/6-31G*）

| N | 类 | VDE (kcal/mol) | VDE/π | 符号符合 4n+2 |
|---|----|----------------|-------|----------------|
| 8 | 4n | +12.95 | +1.619 | ✓ |
| 10 | 4n+2 | −12.17 | −1.217 | ✓ |
| 12 | 4n | +6.01 | +0.501 | ✓ |
| 14 | 4n+2 | −7.54 | −0.538 | ✓ |
| 16 | 4n | +1.88 | +0.117 | ✓ |
| 18 | 4n+2 | −5.52 | −0.306 | ✓ |

### 3.2 \|VDE/π\| 差距收敛

| 配对 | gap | 解读 |
|------|-----|------|
| 8 vs 10 | 2.836 | 小环强分离 |
| 12 vs 14 | 1.040 | 收敛中 |
| 16 vs 18 | **0.424** | 大环接近 |

### 3.3 敏感性

| 检验 | N | 结果 |
|------|---|------|
| 2011-lite vs 2007 | 8 / 10 / 12 | 符号全对；\|Δ(VDE/π)\| ≤ 0.012 |
| BLA 1.34/1.46 | 8 | VDE/π = +1.472（vs 主序 +1.619），符号不变 |

## 4. 协议限定（不改判）

- VDE 用**独立 2007 ESE 代理**，非原著 Table 9-5 的 EV(2011) 绝对值，故只做符号与趋势对照。
- 仅平面 Kekulé；真实大环的非平面构象未纳入。
- N=20–26 未扫（全 B3LYP 成本过高）；判据阈值 N≳16–18 已被 N=8–18 序列覆盖，且 gap 已降至 0.42。
- N=16 的 BLA 变体因 GL Newton 停滞中止，已隔离，不入正式表。

## 5. 专家异议预案

| 可能异议 | 回应 |
|------|------|
| 「没算到 N=26」 | 原著阈值在 N≳16–18；本序列已跨过该阈值且 gap 收敛 2.84→0.42，趋势判据成立。 |
| 「代理量不是原著的 EV」 | 明示为 2007 ESE 代理；只对符号与收敛趋势下结论，不对绝对值对表。 |
| 「平面 Kekulé 不真实」 | 保守设置：平面几何**有利于**保留芳香/反芳香差异，仍观察到收敛，方向不利于反驳。 |
| 「单一键长假设」 | BLA 敏感性已做，符号不翻。 |

## 6. 质控闸

G1 拓扑、G2 几何（dmin=1.085 Å）、G3 收敛（正式点均收敛）、G4 尺度、G5 路径洁净——**全部通过**。中止的 N=16 BLA 已隔离。
