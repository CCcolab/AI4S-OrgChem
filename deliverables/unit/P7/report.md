# P7 技术报告：张力芳香分子的 BLA 归因

## 1. 命题与对立

| | |
|--|--|
| 原著主张 | 苯并三环丁二烯类中心环的键长交替（BLA）源于 π 离域，而非角张力。 |
| 传统对立 | Mills–Nixon：外周小环施加的角张力导致中心环 BLA。 |
| 本项目判据 | 一致：G 几何有大 Δr>0，排除中心–外周 π 耦合（PLG）后 \|Δr\| 显著坍塌；非一致：PLG 后 Δr 基本不变（即张力主导）。 |

## 2. 方法

```bash
PYTHONPATH=. python3 -m src.p7_strained.run_v1c --basis '6-31g*'
```

- 分子：苯并三环丁二烯 C₁₂H₆，D₃ₕ 对称四参数优化得 G
- 观测量：Δr = r_endo − r_exo（中心环内、外键差）
- **PLG**：按公开定义排除中心环(A) 与外周 C=C(B) 之间的 π Fock / 重叠 / 交换耦合，固定平均键长后扫 Δr
- 收敛策略：PLG 用 DIIS → Newton 兜底

## 3. 结果

| 观测量 | 原著 | 本项目 | 判据 |
|--------|------|--------|------|
| Δr(G) | +0.177 Å | **+0.2065 Å** | 大正值 ✓ |
| Δr(PLG) | −0.002 Å | **+0.020 Å**（扫描极小） | 趋近 0 ✓ |
| 下降幅度 | — | **0.1865 Å** | ≫0.05 Å ✓ |
| PLG 能量偏好 | — | E(Δr≈0) 比 E(Δr(G)) 低 **≈11.2 kcal/mol** | 偏好均化 ✓ |

## 4. 物理解读

若 BLA 由角张力驱动，切断中心–外周 π 耦合不应使其消失。实测 BLA 从 0.21 Å 坍塌到 0.02 Å，且 PLG 态在均化几何处能量更低——驱动力归属于 π 离域，与 Mills–Nixon 预期相反。

## 5. 专家异议预案

| 可能异议 | 回应 |
|------|------|
| 「PLG 定义任意」 | 仅按公开 π 块删除定义实现，且删除范围（A–B 的 π Fock/S/K）写入脚本与 JSON，可复核。 |
| 「只有一个分子」 | 承认。苯并环丁二烯等扩展分子列为剩余；本层级结论限于 C₁₂H₆。 |
| 「PLG 扫描未完全自由优化」 | 承认。固定平均键长扫 Δr 是保守设置；更自由的优化预期把 PLG* 从 +0.02 继续推向原著 −0.002，方向不利于反驳。 |
| 「Δr 网格太粗」 | 极小值位置对判据（坍塌与否）不敏感；更密网格属精度改进。 |
