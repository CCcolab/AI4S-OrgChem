# P8 技术报告：呋喃类的 LDE 口径

## 1. 命题与对立

| | |
|--|--|
| 原著主张 | 呋喃类满足 ΔEA>0 且 ΔEA<ΣΔEAm，差值应称「较小去稳定能」LDE，不宜按苯类 ESE 判为芳香；属芳香/非芳香中间态。 |
| 传统对立 | 呋喃、吡咯常被直接列为芳香杂环。 |
| 本项目判据 | 一致：呋喃类 ΔEA>0 且 LDE<0，与苯（ΔEA<0，走 ESE）形成符号分化，且对几何模型与基组稳定；非一致：呋喃类 ΔEA<0（与苯同类），或符号随基组翻转。 |

## 2. 方法

```bash
PYTHONPATH=. python3 -m src.p8_furan.run_v2 --basis '6-31g*' --basis2 '6-31g'
```

- 层次：B3LYP，6-31G*（主）/ 6-31G（敏感性）
- 定域：2007 Fock+S 口径；杂原子 O/N 的 π 片段处理见 `src/localization/hetero_gl.py`
- 参考态：3×GE-m（合并一对允许共轭双键的超片段）
- 几何模型：垂直（模型几何）+ 半绝热（平面 G* 优化后再做垂直分解）

## 3. 结果（kcal/mol）

| 体系 | 模式 | ΔEA | LDE / ESE | 原著 |
|------|------|-----|-----------|------|
| 呋喃 | 垂直 | +28.61 | LDE = **−37.72** | ≈−39.3 |
| 呋喃 | 半绝热 G* | — | LDE = **−39.04** | ≈−39.3 |
| 吡咯 | 垂直 | — | LDE = **−48.20** | ≈−49 |
| 吡咯 | 半绝热 | — | LDE = **−51.35** | 同模式 |
| 噁唑（扩展） | 垂直 | +24.59 | LDE = **−41.17** | ≈−36.3 |
| 苯（对照） | 垂直 | **−6.54** | ESE = **−35.44** | ≈−36 |

基组敏感性：6-31G* vs 6-31G 的 \|ΔLDE\| = **0.68** kcal/mol。

## 5. 物理解读

关键是**符号分化**而非绝对值：呋喃/吡咯/噁唑一律 ΔEA>0（局部去稳定），苯 ΔEA<0。这说明用同一个「ESE<0 即芳香」的判据把呋喃归入苯类，掩盖了两者在定域参考下的定性差异。原著用 LDE 另立口径在方法学上是自洽的。

## 6. 专家异议预案

| 可能异议 | 回应 |
|------|------|
| 「LDE 只是换个名字」 | 不止改名：ΔEA 的**符号**在两类间相反，判据结构不同。 |
| 「杂原子 π 片段划分主观」 | 划分规则写入 `hetero_gl.py` 并落盘 JSON，可复核；噁唑（两个杂原子）作为独立检验未破坏模式。 |
| 「NICS 说呋喃是芳香的」 | NICS 属磁性判据，与能量分解判据不同轴；本项目只作旁证，不入判定。 |
| 「基组太小/只有 B3LYP」 | 双基组 \|ΔLDE\|=0.68；严格 2011 交换删除列为剩余。 |
