# P2 技术报告：共轭去稳定总命题（汇总 + LFMO-lite）

## 1. 命题与对立

| | |
|--|--|
| 原著主张 | π–π、非键 σ–σ 去稳定并驱动畸变；π–σ 亦去稳定但阻碍扭转；大扭转角是三者折中。「共轭稳定化」作为基本原理应被质疑。 |
| 传统对立 | 共轭稳定化使共平面构象最稳定；构象是共轭与位阻的折中。 |
| 本项目判据 | 一致：NBA 型 + 多烯/芳香定域两类均复现「去稳定和/或驱动畸变」；非一致：可辩护分解下符号系统性相反，或畸变驱动力归宿错误。 |

## 2. 口径声明（先读）

本命题**不主张**「一切 π 离域都去稳定」。原著自身分三口径处理，本项目沿用：

- **局部/成对**共轭（ΔEAm、多烯 GL ΔE、呋喃 ΔEA）→ 去稳定（正）
- **苯环额外**离域（ESE）→ 稳定（负）
- **几何效应**（BLA、单键伸长、NBA 扭转）→ π 或电子项倾向畸变

可证伪核心是：传统「共轭稳定化使共平面最稳」在已验分子类上站不住。

## 3. 方法

### 3.1 汇总层（无新 SCF）

```bash
PYTHONPATH=. python3 -m src.p2_aggregate.summarize
```

只引用已过 G1–G5 的单元判定（P1、P3–P9），继承其质控结论；不引用任何 `results/Pn/invalid_*/`。

### 3.2 LFMO-lite 层（独立 AO 代理）

```bash
PYTHONPATH=. python3 -m src.p2_aggregate.run_lfmo_lite
```

- 分子：NBA（Ph–N=CH–Ph），刚性扭转扫描；C-苯环预先拉回亚胺平面
- 层次：RHF/STO-3G（与原著 Ch5 早期 π–σ 分解同层次量级）
- 片段：A = N-苯基；(B+C) = N、C_imine、H、C-苯基
- 按 Fig. 5-15 公开定义构造态能量差：
  - `EV = E(FUD) − E(DSI)` —— π–π，AO 块密度（片段 π 子空间对角化 vs 全域 π）
  - `Enσσ = 2∑ D_μν F_μν` —— 非键 σ–σ 占据耦合，**排除** C–N/C–C 连接键原子
  - `Eπσ = E(G) − E(FUD)` —— π–σ

**合规声明**：这是按公开态定义独立实现的 AO 代理，**不是** Kost 定域 LFMO 的逐比特复现，不与原著 LFMO 绝对值对表。

| θ | EV（π–π） | Enσσ（非键 σ–σ） | Eπσ |

| 0° | +6.07 | +38.31 | 0.00 |

| 30° | +0.43 | +16.82 | −65.72 |

- `dEV/dθ = −0.17` kcal/deg（0–30° 窗）→ 去稳定且**驱动**畸变

- `Eπσ(0°) = 0.00`，与原著 Table 5-16 的 NBA 平面值一致

## 5. 拒收与限定

| 项 | 处置 |
|----|------|
| θ=45° 的 EV=+55.7 kcal | **拒收**：大扭转下 π/σ AO 指派失稳，不纳入 EV 判据窗（0–30°） |
| Eπσ 随 θ 的阻力斜率 | **未隔离**：AO 代理在大扭转出现 π 指派与电子数泄漏，只报平面值 |
| 早期约束 SCF 路线（FUD/DSI 定域 SCF） | **放弃**：θ>0 时不收敛、量级失真，未写入任何正式表 |

## 6. 专家异议预案

| 可能异议 | 回应 |
|------|------|
| 「这不是真 LFMO」 | 明确承认。本层级只声称按公开态定义的 AO 代理复现了 EV、Enσσ 的**符号与斜率**，不声称复现 Kost 数值。 |
| 「能量分解不唯一」 | 固定公开 GL/ESE 与 Fig. 5-15 口径，并把口径写在判定书首段；不同分解下的数值差异属方法学，不改本项目符号级结论。 |
| 「总命题过宽」 | 已在口径声明中排除「苯 ESE 也去稳定」这一读法。 |
| 「STO-3G 太小」 | 与原著同层次的早期 π–σ 分解一致；P3–P9 的主证据均在 B3LYP/6-31G* 上独立成立。 |
| 「P1 非一致是否推翻 P2」 | 不推翻。P1 否掉的是**经典热化学叙事的可复现性**，而定域层面 GL ΔE≈+4.06 仍为去稳定同号。作缺口披露。 |
