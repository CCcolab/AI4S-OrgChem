# P3 技术报告：NBA 大扭转角

## 1. 命题与对立

| | |
|--|--|
| 原著主张 | 晶体 θ≈36°–55°；弛豫 PES 大角能量最低；该点 EN↑、Ee↓ |
| 传统对立 | 位阻去稳定 → 拥挤构象升高 |
| 本项目判据 | 一致：E_min∈[30°,60°] 且 EN↑/Ee↓；非一致：近平面全局最低，或大角显著更高 |

## 2. 方法（加严重扫，正式）

- θ = C_ortho(N–Ph)–C_ipso(N–Ph)–N–C_imine  
- **A**：级联自由预松弛 RHF/STO-3G → RHF/3-21G  
- **B**：双向序贯 θ 约束弛豫（RHF/3-21G，惩罚刚度可升级重试）  
- **C**：B3LYP/6-31G* 单点；每角取上下扫较低能  
- **质控闸**：ΔE 跨度 ≤25 kcal；θ 误差 ≤3°；拓扑完好；滞后 ≤1 kcal 或全点梯度收敛  
- **独立复核**：同种子起 B3LYP/6-31G* 无约束自由松弛  

入口：`python3 -m src.p3_nba.run_tight`（见实施表）。
