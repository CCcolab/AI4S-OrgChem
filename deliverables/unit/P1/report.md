# P1 技术报告：丁二烯共轭能与参考分子敏感性

## 1. 命题与传统对立

| | |
|--|--|
| 原著主张 | 经典用 1-丁烯得 CE≈−3.9（稳定化）是「选择性摘取」；改用氢化主中间体 trans-2-丁烯则 CE≈+1.9（去稳定）。GL≈+1.4。 |
| 传统对立 | 丁二烯相对两分子 1-丁烯的氢化热差证明共轭稳定化。 |
| 本项目判据 | 独立计算 CE1<0 且 CE2>0（且 CE2~+1–3 kcal/mol）→ 一致；否则非一致。 |

## 2. 方法

- 引擎：WSL PySCF 2.14.0（不改环境）
- 层次：RHF / B3LYP / MP2（MP2 = RHF 优化几何 + MP2 能量），基组 6-31G*
- 物种：H₂、反式-1,3-丁二烯、1-丁烯、trans-2-丁烯、正丁烷
- 优化：`scipy.optimize.minimize(BFGS)` + `mf.nuc_grad_method()`；结果写入 `opt_success` / `|g|_max` / `quality_gate`
- 敏感性：`python3 -m src.p1_butadiene.run --sensitivity --basis '6-31g*'`
- ZPE：`python3 -m src.p1_butadiene.run_zpe`（谐波，落盘几何，不重优化）
- L3 GL：`python3 -m src.p1_butadiene.run_gl`（Ch6 2007：π-AO 识别 + Fock/重叠块删除）

能量定义见 `VERDICT.md`。

## 4. 为何未出现符号翻转？

实验上需满足：

`2|ΔH(trans-2)| < |ΔH(丁二烯)| < 2|ΔH(1-丁烯)|`

本项目电子能与 ZPE 校正均满足 `|ΔH(丁二烯)|` 小于两侧两倍氢化热绝对值，故 CE1、CE2 同号为正。

## 5. 实验热化学算术（附录，不改判定）

用典型实验氢化热（约值，kcal/mol）：1-丁烯 ≈ −30.3，trans-2-丁烯 ≈ −27.6，丁二烯→丁烷 ≈ −57.1，则参考选择可改变叙事。正式判定仍绑定**独立 QC 复现判据** → **非一致**。
