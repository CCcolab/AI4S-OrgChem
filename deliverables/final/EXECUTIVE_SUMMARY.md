## 一句话结论

在原著自身公开的定义与参考态口径下，**九条核心命题中八条可被第三方独立复现（一致），一条不可（非一致）**。这既不等于传统共轭/芳香性理论被推翻，也不等于原著的能量分解是唯一正确的物理图像。

## 八项复现成功中最硬的三条

1. **P6 无参数 ESE 基准命中**。苯 ESE = **−35.44** kcal/mol（原著 −36.3，实验口径约 −36）；环丁二烯垂直 ΔEA = **+53.98**（原著 +53.6）。两个方向相反的基准同时命中，且不依赖任何经验参数或等键反应选取——这是整个方法体系最强的自证。

2. **P7 对 Mills–Nixon 的直接反证**。苯并三环丁二烯中心环 BLA 在完整几何下为 **+0.207 Å**；一旦按公开定义切断中心环与外周 C=C 的 π 耦合，BLA 坍塌到 **+0.020 Å**。若 BLA 由角张力驱动，切断 π 耦合不应使其消失。

3. **P3 拥挤构象最稳的可复现性**。NBA 弛豫 PES 的能量最低点在 **θ ≈ 44.9°**，无约束自由优化独立落在 **≈34.5°**，与晶体学量级一致；近平面构象并非最稳。这直接冲击「共轭稳定化使共平面最稳」的教科书直觉。

## 那条非一致：P1

原著叙事需要 **CE₁ < 0 且 CE₂ > 0**（换参考分子则共轭能符号翻转）。本项目在 RHF、B3LYP、MP2、B3LYP+ZPE 四种层次下算得 CE₁ 恒为正（+8.1 至 +9.3 kcal/mol），**未出现符号翻转**；按 Ch6 公开定义自研的 2007-GL 给出 ΔE = +4.06 kcal/mol，与去稳定同号，但未落入书中 +1.4 的容差。

因此 P1 判 **非一致**。这不推翻定域层面的证据（GL 仍为去稳定），但意味着**用经典氢化热差作为「共轭能可正可负」的入口论证，在我们的独立复现中不成立**。

保留这条异议是本报告可信度的一部分：一个全票通过的验证管线无法自证不是背书。

## 必须同时说明的三条限定

1. **判定是"可复现性"判定，不是"物理正确性"判定**。「一致」意味着在原著定义下数值与符号能被独立复现，不意味着该分解是唯一或最优的物理解释。
2. **能量分解本身参考态依赖**。这是该领域的公认弱点，我们没有回避：所有口径（GL / GE-m / ESE / VR / PLG）均显式落盘，并附层次与基组敏感性。
3. **原著自己就分口径**。局部/成对共轭去稳定（ΔEAm>0）与苯环额外离域稳定（ESE<0）是两件事。任何把本项目读成「一切共轭都去稳定」的说法都是误读。

## 方法学副产品（AI4S Agent · 独立价值）

本项目是采用**最新 AI 技术**的 **AI for Science（AI4S）Agent** 实践：智能体在预注册判据下端到端执行，形成可审计管线——**判据先行 → 硬证据闸（G1–G5）→ 作废数据隔离 → 判定书唯一落盘**（聊天结论不作正式判定）。

其中 P3 是关键案例：初版曾因建环 bug（生成了七元含氮环）与欠收敛 PES 得出"非一致"的错误读数，被质控闸拦下、坏数据归档至 `invalid_wrong_geometry/`，修正后翻为"一致"。**判定的翻转来自纠正方法学错误，而非同一证据改口**——这条审计轨迹本身构成 AI4S Agent 方法学的可引用案例。
