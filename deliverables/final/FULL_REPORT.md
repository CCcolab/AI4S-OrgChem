## 1. 研究体裁与定位

本项目是一项采用**最新 AI 技术**的 **AI for Science（AI4S）Agent** 工程，同时构成**独立复现研究（replication / verification study）**——不是立场论战，也不是原著的推广材料，更不是「用聊天模型口头赞同或否定原著」。

**AI4S Agent 含义**：前沿大模型智能体在项目级 Rule 与硬证据门禁约束下，完成命题拆解、独立编码、PySCF 计算编排、质控与 `VERDICT` 落盘；科学权威来自门禁授权的证据链，而非模型文笔。

它同时是「**三大 LLM Agent 独立验证**」计划中的一支：本仓库全部判定与实现由本支路 **AI4S Agent** 独立完成；另两支应由不同大模型 Agent 在独立仓库中重做，事后交叉比对。本报告数值与结论**仅约束本支路**。

三个刻意的设计选择决定了它的定位：

| 设计 | 目的 |
|------|------|
| **判据先行** | 每条命题的自变量、观测量、阈值、一致/非一致条件在计算之前写入 `implementation/Pn_*计划实施表.md`，事后不得放宽 |
| **仅凭公开定义独立实现** | 不接触原著程序，检验的是「这些主张在**定义层面**是否可复现」，而非复算既有数字 |
| **硬证据闸** | G1–G5（拓扑/几何/收敛/尺度/路径）不过则只能写「待定」，禁止在未收敛或错误分子上定判 |

### 1.1 判定语义（关键）

「一致 / 非一致」是**可复现性**判定：

- **一致** = 在原著自身的定义与参考态口径下，独立实现能复现其符号与量级，且能经受对参考态/方法选择的追问。
- **非一致** = 独立结果在符号、量级或关键结论上相悖，或该论断在其自身定义下不可复现。

「一致」**不等于**：该分解是唯一正确的物理图像；也**不等于**传统理论被推翻。这一区分贯穿全报告。

## 3. 结果综述

九命题的实测值、阈值与达阈情况见 [`VERDICT_TABLE.md`](VERDICT_TABLE.md)。此处只做跨命题的结构性归纳。

### 3.1 复现成功的证据簇

**簇 A — 无参数能量基准（P6, P8）**  
最强的一簇。P6 用同一套定域 + 虚拟参考流程，同时命中两个**方向相反**的基准：苯 ESE = −35.44（稳定），环丁二烯 ΔEA = +53.98（去稳定）。P8 把同一流程推广到杂环，得到呋喃类 ΔEA>0 与苯 ΔEA<0 的符号分化。这一簇的说服力来自「一套流程、多个符号方向、无可调参数」。

**簇 B — 几何归因（P4, P7）**  
沿冻结 BLA 路径与定域对照描述几何分量。P4：趋向等键长时 ΔEN = −96、ΔEe = +88 kcal/mol（符号达阈；E_tot/EN 极小在 δ=0；**不写因果驱动**）。P7：C₁₂H₆ 切断 π 耦合后中心环 BLA 从 0.207 Å 坍塌到 0.020 Å（单体系；与 Mills–Nixon 角张力主导预期不符）。

**簇 C — 构象反例（P3, P2）**  
P3 给出「拥挤大扭转可为最稳」的可复现实例（θ_min≈44.9°，自由优化≈34.5°）。P2 在 NBA 上进一步给出去稳定项随扭转下降的定量刻画（dEV/dθ<0、dEnσσ/dθ<0），即这些项不只是去稳定，还**驱动**畸变。

**簇 D — 趋势收敛（P5, P9）**  
P5：ΔEAm 6/6 全正且单键伸长；P9：4n/4n+2 的 \|VDE/π\| 差距随 N 从 2.836 单调收敛到 0.424。两者都是「模式」而非单点，抗单点巧合的能力更强。

### 3.2 未复现的一条：P1

原著的入口论证是：经典用 1-丁烯作参考得 CE ≈ −3.9（稳定），改用氢化主中间体 trans-2-丁烯则 CE ≈ +1.9（去稳定），因此「共轭能的符号取决于参考分子选择」。

本项目算得（B3LYP/6-31G*，kcal/mol）：

| 量 | 本项目 | 原著 |
|----|--------|------|
| CE₁（vs 1-丁烯） | **+9.331** | −3.9 |
| CE₂（vs trans-2-丁烯） | **+1.861** | +1.9 |

CE₂ 与原著相当接近，但 CE₁ **符号相同为正**，翻转不存在。四种层次（RHF / B3LYP / MP2 / +ZPE）一致，故不是方法学偶然。

结构原因：符号翻转要求 `2|ΔH(trans-2)| < |ΔH(丁二烯)| < 2|ΔH(1-丁烯)|`。本项目的电子能与 ZPE 校正均给出 `|ΔH(丁二烯)|` 小于两侧两倍氢化热，故 CE₁、CE₂ 同号。用文献实验氢化热做同样算术**可以**复现参考态叙事的变化（见 `unit/P1/report.md` §5），但项目边界规定正式判定绑定独立量子化学复现，故判 **非一致**。

L3 子结论：按 Ch6 公开 2007 定义自研 GL，丁二烯 ΔE = +4.06 kcal/mol，去稳定同号但量级偏大，未落入书中 +1.4（原著 Ch12 明示该数出自 2014 法，含交换积分删除）。因此对「≈+1.4」也判非一致（量级）。

**P1 与 P2 的关系**：P1 否掉的是热化学入口叙事的可复现性，不是定域层面的去稳定结论。P2 在汇总时把 P1 作为**披露的缺口**处理，不用它推翻定域证据，也不用定域证据回溯改写 P1。

## 4. 专家异议与回应

### 4.1 「能量分解不唯一，你们选的口径有利于原著」

**接受前提，拒绝推论。** 参考态依赖是能量分解分析的公认弱点。我们的处理是：

1. 所有口径（GL / GE-m / ESE / VR / PLG / LFMO-lite）显式写入脚本并落盘 JSON，可逐项复核；
2. 每条命题附层次或基组敏感性，符号在敏感性下不翻转才算达阈；
3. 判定语义限定为「在该口径下可复现」，而非「该口径正确」。

换口径可能改变数值，但要推翻本报告的符号级结论，需要给出一个**同样自洽、同样无参数、且能同时解释 P6 两个反向基准**的替代分解。这是可检验的挑战，不是修辞。

### 4.2 「一致 8 项，是不是 AI 在讨好原著？」

反证有三：

1. **P1 判非一致**，且是原著的入口论证；
2. **P3 曾被自己的门禁否掉**——初版错误几何给出的"非一致"读数被拒收、归档、重跑，翻转过程完整留痕；
3. 每条命题都保留了**拒收清单**（如 P2 的 θ=45° EV、P9 的 N=16 BLA），而非把所有数据都算成证据。

### 4.3 「这推翻了共轭稳定化理论吗？」

**没有，本报告不作此主张。** 传统共轭稳定化的证据基础包括光谱、旋转势垒、键长趋势、反应性等多条独立线索，本项目只检验了原著所挑战的那一部分——主要是**基于热化学与能量分解的稳定化能论证**。可以说的是：

- 「共轭稳定化使共平面构象最稳」这一常见推论，在 NBA、多烯、张力芳香三类体系上不成立；
- 局部/成对共轭在定域参考下呈去稳定，这一结论是可独立复现的；
- 苯环层面的额外离域仍为稳定（ESE<0），原著自己也如此处理。

### 4.4 「STO-3G / 6-31G* 太小，会不会是基组假象？」

P8 做了双基组（\|ΔLDE\|=0.68 kcal），P9 做了 2011-lite 与 BLA 两种敏感性（符号不翻），P1 做了四层次交叉。P2 的 LFMO-lite 用 STO-3G 是为与原著早期 π–σ 分解同层次；该命题的主证据（P3–P9）均在 B3LYP/6-31G* 上独立成立。更大基组与更高相关层次列为剩余，但没有迹象表明符号依赖基组。

### 4.5 「你们没有原著的程序，凭什么说复现了？」

正因为没有。使用原著程序只能验证「同一代码给出同一数字」；按公开定义独立实现才能验证「这些主张在定义层面成立」。代价是数值不会逐位吻合（如 P2 的 LFMO-lite 明确声明不与 Kost 数值对表，P9 的 VDE 为 2007 ESE 代理而非 EV(2011)）——这些限定逐条写在对应 `VERDICT.md` 中，不掩盖。
