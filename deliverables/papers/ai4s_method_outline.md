## 核心论点（全文只服务这一句）

> LLM Agent 在科学计算任务上的主要风险不是算不出来，而是**算错了却给出自信结论**。仅靠更强的模型或更好的提示无法消除这一风险；需要把「什么算证据」外化成机器可判的门禁，并让判定只能由门禁授权产生。

## Abstract

1. 背景：Agent 被越来越多用于端到端科研任务，但评测多聚焦"能否完成"，少有机制保证"结论是否被证据支持"。
2. 问题：失败模式不是崩溃而是**静默错误** —— 建错分子、优化未收敛、能量尺度荒谬，而 Agent 仍给出流畅且自信的结论。
3. 我们的方法：预注册判据 + 五道硬证据门禁（拓扑 / 几何 / 收敛 / 尺度 / 路径洁净）+ 作废数据隔离 + 判定唯一落盘。
4. 案例：一项跨 9 条命题、约 6 周的量子化学复现项目。**门禁拦下了一个已成形的错误判定并使其反转**。
5. 结论与可迁移性：门禁设计的一般原则，及其在其它计算科学领域的对应物。

## 1. Introduction

- Agentic science 现状与评测方式（任务完成率、benchmark 通过率）。
- **被忽视的失败模式**：静默错误 + 自信表达。为什么它比崩溃更危险——崩溃会被发现，错误结论会被引用。
- 为什么提示工程与自我反思不足够：Agent 无法从自己的错误输出中检测出「这个分子建错了」——它缺的是**领域断言**，不是推理能力。
- 贡献：(i) 一套领域特定但可迁移的门禁规格；(ii) 一份完整审计轨迹的真实案例（含一次判定反转）；(iii) 门禁设计的一般化原则。

## 3. 系统设计

### 3.1 判定纪律
- 判定只允许「一致 / 非一致 / 待定」，且**只能写入指定文件**，聊天输出不作数。
- **待定 ≠ 失败**：设计上必须让 Agent 有一个"证据不足"的合法出口，否则它会被逼着编结论。这是全系统最关键的一条。

### 3.2 预注册判据
判据（自变量、观测量、阈值、判定条件）在计算前写入追踪文件，事后不得放宽。防的是"看到结果再定标准"。

### 3.3 五道门禁

| 门禁 | 断言对象 | 领域实例 | 失败处置 |
|------|----------|----------|----------|
| G1 | 对象正确性 | 键连 / 配位数 / 环尺寸断言 | 立即 `SystemExit`，不算能量 |
| G2 | 对象健全性 | 原子最小间距、键长窗 | 中止 |
| G3 | 数值收敛 | 优化达阈，或独立代理（双向扫描滞后） | 禁止用于判定 |
| G4 | 尺度合理性 | ΔE 落在预声明化学窗 | 拒收本轮 |
| G5 | 路径洁净 | 正式表与作废数据物理隔离 | 迁移至 `invalid_*/` |

**G1 是收益最高的一道**：它拦住的是"算的根本不是目标对象"这类无法从能量数值看出的错误。

### 3.4 机制而非规范
门禁必须是**代码**而不是文档条款：脚本产出的 JSON 强制带 `quality_gate` 字段，`passed != true` 时脚本非零退出且判定字段置 `null`。Agent 无法绕过一个不返回结论的函数。

### 3.5 作废数据隔离
错误协议的产物不删除（保留可审计性）但物理迁出正式路径，并在结题清单中逐条声明。

## 4. 案例研究

### 4.1 任务
对一部质疑传统有机结构理论的专著的九条核心命题做独立复现（不接触原著代码，仅凭公开定义实现）。最终 8 一致 / 1 非一致。

### 4.2 关键事件：一次被拦下的错误判定 ★

**本文的核心证据，需详写。**

| 阶段 | 内容 |
|------|------|
| 初始输出 | Agent 完成 NBA 扭转角 PES 扫描，得出"近平面最稳、大角显著更高"，据此准备写「非一致」 |
| 表面证据 | 曲线光滑、数值有序、叙述自洽——**从输出看不出任何问题** |
| G1 拦截 | 拓扑断言失败：构建脚本的成环逻辑生成了七元含氮环，算的**不是** N-苯亚甲基苯胺 |
| G3 拦截 | 同批扫描存在欠收敛点，PES 为假 |
| 处置 | 全部旧数据迁入 `results/P3/invalid_wrong_geometry/`，判定回退为待定 |
| 重跑 | 修正建环 + 双向序贯约束弛豫（滞后 0.28 kcal/mol 作为收敛代理）+ 无约束自由优化独立复核 |
| 反转 | 最稳构象 θ≈44.9°，自由优化独立落在 ≈34.5° → 判定「一致」 |

**要强调的点**：判定的反转来自**纠正方法学错误**，不是同一证据下改口。没有 G1，这个错误判定会带着完整"证据链"进入最终报告，而且看不出问题。

### 4.3 其它门禁触发
- 能量尺度门禁拦下构象差达 10² kcal/mol 的荒谬结果（提示约束 SCF 未收敛）
- π/σ AO 指派在大扭转角失稳 → 相应数据点排除于判据窗而非解释成"惊人发现"
- 定域态约束 SCF 路线整体放弃（收敛失败），改用非变分密度构造并明示其非变分性

### 4.4 成本
门禁的开销（断言编写、重跑、拒收数据）vs 一个错误结论进入正式报告的代价。定量给出：拒收/重跑约占总计算量的比例。

## 5. 一般化原则

从案例抽出可迁移条款：

1. **先断言对象，再算指标**。任何"指标算对了但对象错了"的领域都需要 G1 类断言。
2. **给 Agent 一个合法的"我不知道"**。没有这个出口，对齐压力会转化为编造。
3. **门禁必须是代码**。写在规范里的门禁等于没有。
4. **不删除错误数据**，只隔离。审计轨迹本身是产出。
5. **判定的唯一落盘位置**。区分"Agent 的话"与"项目的判定"。
6. **判据先于数据**。

### 5.1 跨领域映射

| 领域 | G1（对象） | G3（收敛） | G4（尺度） |
|------|-----------|-----------|-----------|
| 量子化学 | 分子拓扑断言 | SCF/优化收敛 | ΔE 化学窗 |
| 分子动力学 | 拓扑 + 力场指派 | 能量守恒 / 平衡判据 | 温度、压强合理性 |
| 机器学习实验 | 数据集划分无泄漏 | 训练收敛 / 种子稳定性 | 指标不超过理论上界 |
| 数值 PDE | 边界条件与网格 | 网格收敛研究 | 守恒量残差 |

## 6. Limitations

- 单项目 N=1，无对照组（没有"不加门禁"的平行运行可比）
- 门禁的领域断言需人工设计，成本不低
- 门禁只能拦已知失败模式；未知失败模式仍会漏过
- 本项目的 Agent 与人类监督比例未做严格量化

## 7. Conclusion

对齐的重点不只是让模型"说话谨慎"，而是让**结论的产生路径受机制约束**。当判定只能由通过门禁的证据授权产生时，"自信的错误"的空间被压缩了。
