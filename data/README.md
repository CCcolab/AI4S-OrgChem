# data/（仅本地 · 不入库）

本目录用于存放由原著 PDF **本机抽取** 的派生文本（如 `book_full.txt`、`book_text/page_*.txt`），仅供验证者检索公开定义与页码时使用。

## 规则

1. **永不** 将全书或分页抽文本推送到 GitHub（等同再分发受版权保护的文字）。
2. 公开仓库中的命题规格、公式说明与判定依据写在 `docs/`、`implementation/`、`deliverables/`；读者对照原著时请自行获取纸质或合法电子版。
3. 抽取工具若存在于 `tools/`，也不得把输出提交进版本库。

克隆仓库后如需本地全文检索，请在依法获得 PDF 后自行抽取到本目录，并确认 `.gitignore` 已忽略这些文件。
