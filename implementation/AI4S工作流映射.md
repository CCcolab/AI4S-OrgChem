# AI4S 工作流映射（重新确认：流程可取，工具需筛选）

> 参考文章：[一条更现实的量子化学 AI4S 工作流](https://mp.weixin.qq.com/s/v6qcn_LI7ZdcoxB0xIcO3A)  
> **结论先说**：文章的**七步流程思想**适合本项目；文章点名的**软件工具并不都应成为本项目工具链**。须按 P1–P9「电子结构可证伪对照 → 一致/非一致」重评。

## 0. 总判定

| 维度 | 是否采用 | 说明 |
|------|----------|------|
| 七步工作流（问题→结构→计算→对照→扩规模→找规律→人类终判） | **采用（改编）** | 与第三方验证、可测试对照、人类终裁高度一致 |
| 文章工具清单整包搬用 | **不采用** | 多数工具服务的是「通用 AI4S 演示」；本项目核心是 **DFT/HF 级电子结构分解与热化学对照** |
| 本项目默认工具链 | **PySCF + 自研对照脚本 + Cursor Agent**（ASE 可选） | 见下文分级 |

## 一、文章七步：保留什么

```
定义科学问题 → 准备分子结构 → 运行量子化学计算
→ 构造可测试的对照 → （有条件地）扩大规模
→ （有条件地）归纳候选模式 → 独立复核并由人类判断
```

对本项目的含义：

- **必须做**：步骤 1、3、4、7（命题、高精度计算、对照、人类判定）。  
- **必须插入**：步骤 3 与 4 之间——**证据质控硬闸**（拓扑/正确分子、收敛、能量尺度）；未过闸不得进入终裁。见 [`docs/quality_gates.md`](../docs/quality_gates.md)。  
- **按需做**：步骤 2（分子小，结构准备可极简，但**不可省略拓扑自检**）、步骤 5（敏感性批量，仍用 PySCF，不用 ML 势函数冒充证据）、步骤 6（验证任务不依赖“发现新公式”）。

```
定义科学问题 → 准备分子结构（含拓扑断言）→ 运行量子化学计算
→ ★ 质控闸 G1–G5 → 构造可测试的对照
→ （有条件地）扩大规模 → （有条件地）归纳 → 独立复核并由人类判断
```

**严禁**：未收敛或错误分子上的能量曲线 → 直接写一致/非一致。

## 二、文章工具逐项适合性评审

评审标准（对本项目）：

1. 能否支撑 **P1–P9 的判定证据**（符号、量级、对照）？  
2. 专家是否会接受该工具产出作为「验证原著反传统论断」的主证据？  
3. 是否触及原著方法核心（定域矩阵约束、Ee/EN、ESE 等），而不仅是通用分子模拟？

| 工具 | 适合性 | 评级 | 理由 |
|------|--------|------|------|
| **PySCF** | **适合且必需** | ★★★ 核心 | 唯一已装且能做 SCF/DFT/梯度、并支持自研矩阵级定域（P5–P8）的引擎；主证据必须来自此类电子结构计算 |
| **Cursor / 科学 Agent** | **适合且必需** | ★★★ 核心 | 命题形式化、任务编排、敏感性设计、报告与 Canvas、判定草稿；对应步骤 1/5/7 |
| **ASE** | **可选、非核心** | ★☆☆ 辅助 | 已装 3.29.0，便于几何/优化接口；但 PySCF 自带优化即可。**不产生** CE/ESE/ΔEAm 主证据 |
| **RDKit** | **基本不需要** | ☆☆☆ 可缺省 | 体系均为小分子、结构已知；笛卡尔/Z-matrix + 文献几何足够。装了只省手工，不改善判定可信度 |
| **Psi4** | **非必需** | ☆☆☆ 可缺省 | 仅能给 P1/P3/P4 类「普通能量」做交叉验证；**难以优雅实现**原著式 Fock/定域手术。双引擎增加复杂度，收益低 |
| **MACE** | **不适合作为主证据** | ✗ 慎用 | ML 力场不能用来裁定共轭稳定/去稳定、芳香 ESE 等电子结构主张；用作主证据时专家会直接提出方法学异议。仅当 P9 超大环需要粗筛几何时，才可作**预处理**，精算仍须 PySCF，且报告须标明 |
| **PySR** | **不适合作为验证主线** | ✗ 慎用 | 本项目交付是「是否支持原著已给出的论断」，不是「从数据发现新经验公式」。有大量 ΔEAm–Δr 点后可作探索性附录，**不得**作为一致/非一致的判据来源 |

### 一句话

> **流程学文章，工具按命题裁剪：主栈 = PySCF + 自研脚本 + Agent；ASE 可有可无；RDKit/Psi4/MACE/PySR 默认不纳入本项目论证工具链。**

## 三、本项目推荐工具链（修订版）

### 3.1 默认（即刻可用，不新增安装）

| 层级 | 工具 | 用途 |
|------|------|------|
| 电子结构主引擎 | **PySCF 2.14.0（WSL）** | 优化、单点、PES、Ee/EN、后续定域/分解 |
| 编排与交付 | **Cursor Agent + Canvas** | 命题、脚本、报告、判定 |
| 数值栈 | NumPy / SciPy / h5py（已随 PySCF 环境） | 矩阵与数据分析 |
| 文档与 PDF | Windows 侧 PyMuPDF 等 | 抽取公开定义与数值表 |

### 3.2 可选（仅当明确需要且你批准）

| 工具 | 允许场景 | 不允许场景 |
|------|----------|------------|
| ASE | 统一几何 I/O、批量优化驱动 | 用 ASE/ML 计算器替代 PySCF 能量作为判定依据 |
| Psi4 | P1 热化学能量的第二引擎抽查 | 替代定域方法实现 |
| RDKit | 大量衍生物枚举（当前 P1–P9 无此需求） | — |
| MACE | 大环构象粗筛（预处理） | 任何「共轭能/芳香能」结论 |
| PySR | 验证完成后的探索性附录 | 写入正式「一致/非一致」判据 |

### 3.3 本项目真正「缺」的，不是文章里的那些库

原著验证的难点在于**方法实现**，而非再装一套 AI4S 演示软件：

| 能力 | 对应命题 | 实现方式 |
|------|----------|----------|
| 热化学对照 CE₁/CE₂ | P1 | PySCF + 自研反应能脚本 |
| 扭转 PES + Ee/EN | P3, P4 | PySCF |
| GL / GE-m 定域几何 | P5, P6, P8 | **自研**（按 PDF 公开定义改矩阵/约束） |
| ESE / VR | P6 | **自研** |
| PLG | P7 | **自研** |
| LFMO / π–σ 分解 | P2 | **自研**（仅公开定义） |

这些自研模块才是与文章通用工具链的**本质差别**。

## 四、七步 ↔ 本项目（按修订后工具）

| 步骤 | 是否必须 | 本项目做法 | 用什么 |
|------|----------|------------|--------|
| 1. 定义科学问题 | 必须 | P1–P9 规格与判据 | Agent + `docs/propositions.md` |
| 2. 准备分子结构 | 必须（含拓扑自检） | 建几何 + `check_topology`（或等价） | PySCF `Mole`（ASE 可选） |
| 3. 运行量子化学计算 | 必须 | DFT/HF（及必要的 MP2 交叉） | **仅 PySCF** |
| 3b. **证据质控闸 G1–G5** | **必须** | 正确分子/收敛或滞后/能量尺度；未过则待定 | 自研断言 + `quality_gate` JSON；见 [`docs/quality_gates.md`](../docs/quality_gates.md) |
| 4. 构造可测试的对照 | 必须 | 见命题对照表；**仅用过闸数据** | PySCF + 自研分析 |
| 5. 扩大计算规模 | 按需 | 方法/基组/构象敏感性批量 | Agent 编排 **PySCF** 任务（不用 MACE 作证据） |
| 6. 寻找候选规律 | 非必须 | 验证阶段以核对原著数值为主 | 表格/统计即可；不用 PySR |
| 7. 人类终判 | 必须 | Canvas + 一致/非一致回填；未过闸禁止终裁 | Agent 辅助，人确认 |

## 六、对先前文档口径的修正

此前映射中「策略：ASE+PySCF…；RDKit/Psi4/MACE/PySR 批准后启用」易被读成**默认要向文章工具链看齐**。现修正为：

1. **不默认启用** RDKit、Psi4、MACE、PySR。  
2. ASE **可用但不强制**。  
3. 文章价值在于**工作流纪律**（尤其是「可测试对照」与「人类终判」），不在于工具品牌列表。
