## 二、工具不同时，如何避免被作者提出合理异议？

### 2.1 原则：先「拆主张」，再「对口径」

原著 P1 相关论述其实含 **三层主张**，不可混成一句「你没用我的程序所以无效」：

| 层级 | 主张内容 | 原著依据 | 本项目验证手段 | 是否必须用原著程序 |
|------|----------|----------|----------------|--------------------|
| **L1 热化学逻辑** | 同一套氢化热公式下，换参考分子可改变「稳定/去稳定」叙事 | 实验氢化热差（1-丁烯 vs trans-2-丁烯） | 公开实验 ΔH 算术 + 独立 QC 电子能 CE₁/CE₂ | **否**（与程序无关） |
| **L2 经典证据批评** | −3.9 不能当作无可争议的共轭稳定证据 | 对参考选择的方法论批评 | 检验「符号翻转」是否在明确定义下出现 | **否** |
| **L3 GL 数值** | 定域几何法得 CE≈+1.4 kcal/mol | 原著自研 GL（书中丁二烯 +1.4 属 **2014**） | **已做** 2007 Fock+S：ΔE≈**+4.06**；对 +1.4 **非一致（量级）** | 不要求抄程序；交换删除归 P5/P6 |

**回应要点（核心句）**：本项目从未声称「用与原著相同的 GL 程序复现了 +1.4」；本层级验证的是 **L1/L2（定义清晰的 CE₁/CE₂ 符号结构）**。作者若指出「程序不同」，须先指明其异议针对的是 L1、L2 还是 L3——L1/L2 不依赖其程序。

### 2.2 方法差异的显式披露（主动写进报告，避免被说成「偷换方法」）

| 项目 | 原著（公开所述） | 本项目本层级 | 差异是否致命？ |
|------|------------------|--------------|----------------|
| 能量类型 | 实验 ΔH；GL 电子/定域能 | B3LYP 电子能 + **ZPE 敏感性** | ZPE 已做，仍无翻转 |
| 参考定义 | CE = ΔH_hyd(丁二烯)−2ΔH_hyd(ref)（书中叙述） | **同一代数定义** | 同口径 |
| 几何 | 晶体/优化（其软件） | PySCF + SciPy BFGS；`quality_gate` 落盘 | 实现不同，收敛已披露 |
| 定域/GL | 有（丁二烯 +1.4≈2014） | **自研 2007 Fock+S** → +4.06 | 可否定「≈+1.4」量级；不可冒称 2014 复现 |

### 2.3 预设作者异议 → 标准回应

| 作者可能提出的异议 | 本项目回应（可直接引用） |
|----------------------|--------------------------|
| 「你没用我的 GL/Gaussian 程序，结论无效」 | L1/L2 不依赖其程序。L3 已按 Ch6 公开定义自研：ΔE≈+4.06，**未**复现 +1.4（书中该数属 2014）；VERDICT 分列 L1/L2 与 L3 子结论。 |
| 「B3LYP 不在我认可的方法列表里」 | 已在报告中限定层级；判定是「在 B3LYP/6-31G* 电子能定义下是否满足预设判据」，不是「宇宙真理」。若作者指定公开可复现的层次，可在不改环境约束下增加敏感性（或经批准扩展工具）。 |
| 「CE₂≈1.86 已接近我的 1.9，应算支持」 | 项目规则：**数值碰巧接近不是充分条件**；一致要求 **CE₁&lt;0 且 CE₂&gt;0（翻转）**。本计算 CE₁、CE₂ **同号**，翻转失败。 |
| 「实验上明明可以翻转，你应判一致」 | 实验算术已作**附录**并承认其支持「参考选择改变叙事」；但交付口径绑定**独立 QC 复现判据**。若改判据为「仅验证实验热化学逻辑」，须书面改定命题后再重判。 |

### 2.4 若要把可辩护强度拉到「作者难以用方法不同一票否决」

建议按优先级补强（均不复制原著代码）：

1. **书面冻结判据**：本表 + `VERDICT.md` 已写明验证的是 L1/L2 还是 L3。  
2. **实验 ΔH 附录固定引用源**（教科书/手册页码），证明 L1 逻辑与程序无关。  
3. **同一定义下多方法敏感性**（RHF / MP2 / 加 ZPE）——看「翻转」是否稳健。  
4. **按 PDF 公开数学定义自研 GL**（真正对打 L3）——完成后可对「+1.4」单独出子判定。  

当前 **~98%**：1–4 已做（含 ZPE 与 2007-GL）；2011/2014 交换删除留给 P5/P6。

|------|-----|-----|----------|
| RHF | +8.130 | +2.449 | 否 |

### 4.2 如何推出「非一致」

预设一致条件（合取）：

1. CE1 &lt; 0  
2. CE2 &gt; 0  
3. 因而出现 **符号翻转**

实际（B3LYP）：CE1 = +9.331 → 条件 1 **假**；CE2 = +1.861 → 条件 2 **真**；二者同号 → 翻转 **假**。  
RHF/MP2 复核：条件 1 仍假，翻转仍假。  
合取为假 ⇒ 正式判定 **非一致**。

**论述要点（防误读）**：

- 「非一致」= **在本项目冻结的 QC 判据下，未能支持原著 L1/L2 所要求的符号翻转结构**；  
- ≠ 「实验上参考选择从不改变叙事」；  
- ≠ 「原著 GL=+1.4 已被精确复现」（本测得 +4.06；书 +1.4 属 2014）。

### 4.3 结果含义分层论述

| 问题 | 本层级结论 |
|------|------------|
| QC 是否复现「CE1 负、CE2 正」？ | **否**（RHF/B3LYP/MP2）→ **非一致** |
| 是否仅因 B3LYP 偶然？ | **否**；三层同号 |
| CE2 是否接近书中 +1.9？ | B3LYP/MP2 **是（~+1.86）**，不能单独改判 |
| 实验氢化热算术是否支持「换参考则叙事变」？ | **可以支持（附录）**，不升级为正式「一致」 |
| 能否说原著程序算错？ | **不能**；未复现其程序/GL |

### 4.4 一句话总述（可放入对外摘要）

> 在公开可复现的 CE₁/CE₂ 定义下，以 PySCF 在 RHF / B3LYP / MP2（6-31G*）下计算电子能，本项目**均未复现**「1-丁烯参考稳定化、trans-2-丁烯参考去稳定化」的符号翻转，故对 P1 主判据给出 **非一致**；该方法与原著 GL 程序不同，故本判定**不覆盖** GL≈+1.4；实验热化学附录表明参考选择问题在实验数据层面仍值得讨论，但未改写本项目 QC 判定口径。

### 4.5 L3（自研 GL）结果

原著 Ch6：平面共轭分子上识别 π-AO，SCF 前将不同双键间 π–π 的 **Fock 与重叠**矩阵元置零，优化得 GL；ΔE = E(G)−E(GL)。Ch12 丁二烯 **+1.4** 明示为 **2014** 法（含交换积分删除）。

本项目实现：`src/localization/gl_2007.py` + `src/p1_butadiene/run_gl.py`（Newton SCF；r23 一维扫描 1.38–1.52 Å）。

| 协议 | ΔE / kcal | r23(GL) / Å | 备注 |
|------|-----------|-------------|------|
| **Fock+S（主）** | **+4.057** | **1.440** | 同号去稳定；相对书 +1.4 **非一致（量级）** |
| Fock-only | −71.8 | 边界 | 诊断对照，不作主证据 |
| 书 2014 | +1.4 | 1.451 | 交换删除未实现 |

**子判定**：对「GL≈+1.4」→ **非一致**；**不回溯**改写 L1/L2「非一致」。模块供 P5/P6 复用。
