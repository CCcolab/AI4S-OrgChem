# source/（仅本地 · 不入库）

本目录用于存放原著 PDF 的 **本机副本**，例如：

`Questioning Fundamental Principles of Organic Chemistry.PDF`

## 规则

1. **永不** `git add` 本目录下的 PDF 或任何二进制原著文件。
2. 公开 GitHub 仓库 **不提供** 该书电子版；读者请自行在网上依法检索下载。
3. 验证脚本与判定 **不依赖** 仓库内是否存在 PDF；对照以公开定义与 `docs/` 中的命题规格为准。

若克隆本仓库后需要本地对照原文，请自行将合法获取的 PDF 放入此目录（或任意本机路径），勿提交。
